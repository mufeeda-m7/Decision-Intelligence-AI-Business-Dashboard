Decision Intelligence AI – Business Dashboard
An interactive business analytics and machine learning project that helps explore sales performance, identify loss-making products, estimate product-level profit, and support pricing and discount decisions through data-driven recommendations.

The project combines business intelligence, exploratory data analysis, a machine learning regression model, rule-based decision recommendations, and an interactive web dashboard.
📌 Project Overview
Business performance is not determined by sales alone. A product may generate high revenue but still result in a loss because of discounts, costs, or pricing decisions. This project uses historical Superstore sales data to examine sales and profit patterns and provide additional decision support.

The dashboard brings together business KPIs, category and regional analysis, loss-making product identification, automated insights, and a profit simulator. Users can select a product, adjust its discount, and view the model's estimated profit and a corresponding recommendation.
🎯 Objectives

- Analyze historical sales and profit data to understand business performance.
- Track key business indicators such as total sales, total profit, profit margin, and business health score.
- Explore sales performance across product categories and regions.
- Identify products and orders that generate losses.
- Study the relationship between sales, quantity, discount, and profit.
- Train a machine learning regression model to estimate profit.
- Generate decision recommendations based on predicted profit.
- Simulate discount scenarios for selected products.
- Present business information through an interactive dashboard.
  ✨ Key Features

1. Business Overview Dashboard

- Displays total sales and total profit.
- Calculates overall profit margin.
- Shows an overall business health score.
- Supports filtering by product category and region.

2. Sales Analytics

- Visualizes total sales by product category.
- Compares profit across business regions.
- Helps identify stronger and weaker areas of business performance.

3. Loss-Making Product Analysis

- Identifies records with negative profit.
- Displays the most loss-making products.
- Provides product category, region, sales, profit, and discount information.
- Helps highlight products that may need pricing or discount review.

4. Machine Learning-Based Profit Prediction

- Uses a trained Linear Regression model.
- Accepts sales, quantity, and discount as input features.
- Predicts the estimated profit for the supplied values.
- Loads the trained model from the models/ directory.

5. Profit Simulator

- Allows the user to select a product from the dataset.
- Uses historical median sales and quantity as the product baseline.
- Lets the user adjust the discount percentage.
- Predicts profit for the selected discount scenario.
- Displays a recommendation and scenario health score.

6. Automated Business Insights
   Generates data-based observations, including:

- Overall profit margin.
- Best-performing and weakest product categories by profit.
- Best-performing and weakest regions by profit.
- Number of loss-making orders.
- A suggested area of focus for reducing losses.

7. Decision Recommendations
   Recommendations are generated using predefined profit thresholds:
   Predicted profit Recommendation
   Above $500 Highly Profitable — Increase Marketing
   Above $0 to $500 Profitable — Maintain Strategy
   -$500 to $0 Low Profit — Reduce Discount
   Below -$500 Loss — Stop Selling / Review Pricing

These are rule-based recommendations implemented in the project; they are not generated by a separate generative AI model.

   🧠 Decision Intelligence Logic
   The project combines machine learning predictions with rule-based business logic to turn predicted profit into understandable recommendations.
   Profit-Based Recommendation
   The predicted profit is checked against predefined thresholds to return an appropriate recommendation.
   Business Health Score
   The overall business health score is calculated from the profit margin.

The implementation maps profit margins between -20% and +20% to a score between 0 and 100, with values outside this range capped at the minimum or maximum score.
Scenario Health Score
The scenario health score adjusts the baseline business health score according to the predicted profit of the selected scenario.

Important: These health scores are custom rule-based indicators implemented for this project. They should be interpreted as decision-support indicators, not as statistically validated business ratings or a separately trained machine learning model.

▶️ How to Run the Project

1. Clone the Repository
   git clone YOUR_GITHUB_REPOSITORY_URL
   cd Decision-Intelligence-AI-Business-Dashboard
   Replace YOUR_GITHUB_REPOSITORY_URL with your actual GitHub repository URL.
2. Create a Virtual Environment
   python -m venv .venv
3. Activate the Virtual Environment
   Windows:
   .venv\Scripts\activate
   macOS / Linux:
   source .venv/bin/activate
4. Install Dependencies
   pip install -r requirements.txt
5. Check the Required Files
   Make sure the following files are present:
   data/superstore.csv
   models/profit_model.pkl
   backend/main.py
   frontend/index.html
   The application loads the existing dataset and trained model from these paths.
6. Start the Backend Server
   Run this command from the project root directory:
   uvicorn backend.main:app --reload
7. Open the Dashboard
   Visit the following address in your browser:
   http://127.0.0.1:8000
   The FastAPI backend serves the frontend pages and provides the API endpoints used by the dashboard.
8. Explore the API Documentation
   FastAPI provides interactive API documentation at:
   http://127.0.0.1:8000/docs

⚠️ Limitations

- The model uses only three input features: Sales, Quantity, and Discount.
- Linear Regression may not capture every complex or nonlinear relationship in business data.
- The current prediction is based on historical dataset patterns.
- Recommendations use predefined thresholds and may not account for every business condition.
- The business health score is a custom formula, not a trained classification model.
- The dataset represents historical transactions and may not reflect current market conditions.
- Actual business profit can also depend on operating costs, shipping expenses, seasonality, competition, and other factors that are not included as model inputs.
- The model evaluation metrics are not currently reported by the supplied training script.
